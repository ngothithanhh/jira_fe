# UI references and attribution

This frontend already derives components from **sanidhyy/jira-clone**. The backlog integration reuses the existing Radix/shadcn components and Tailwind setup. Source: https://github.com/sanidhyy/jira-clone (reference checkout 9e832a1).

The backlog UI also draws visual inspiration from **oldboyxx/jira_clone**, checkout 26a9e77, notably Project/Sidebar, Project/Board/Lists/List/Issue and Project/Board/IssueDetails. Its React 16, styled-components and Webpack implementation has not been imported into this frontend. Source: https://github.com/oldboyxx/jira_clone.

Jira's public Scrum template was consulted for sprint/backlog grouping: https://www.atlassian.com/software/jira/templates/scrum. No Atlassian logo, proprietary source code or product screenshots are bundled in this frontend.
